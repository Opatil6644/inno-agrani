# LLM Accuracy Frameworks
## Frameworks Overview
- LLM Evaluation Harness: A standardized "Truth Engine" for quantifying model intelligence, reasoning, and instruction-following capabilities across diverse academic and professional benchmarks.
- LLaDA Evaluation: A specialized framework for measuring the performance of Large Language Diffusion Action models, validating how non-autoregressive masked diffusion compares to traditional text generation.
- LLaDA Profiling: A deep-telemetry pipeline utilizing NVIDIA Nsight Systems to capture CUDA kernel summaries, GEMM parameters ($M, N, K$ dimensions), and GPU hardware utilization for low-level optimization.
